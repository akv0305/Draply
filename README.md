# Draply
Quick-commerce platform for fashion. Customer PWA + Merchant dashboard + Admin console.

Stack: Next.js 14, Tailwind, shadcn/ui, Prisma, Supabase, Zustand, TanStack Query, Leaflet.

## Setup
1. Copy .env.local.example to .env.local and fill in values.
2. pnpm install
3. pnpm prisma migrate dev (after schema is added)
4. pnpm dev

See /docs/CONVENTIONS.md for code conventions.
